# 精选示例与本机保存

点击顶部「精选示例」，查看「夜雨酒馆 · 江畔金桂」。这个 96 秒静音样段从第二轮 V5 的保存版本找回：29 秒是暖灯酒馆，74 秒是月下金桂。它是人工编排的视觉示例，没有附带《成都》录音或歌词，也不是自动导演的质量验收结果。

- **查看原版**：新标签页只读回放，支持播放、两个亮点跳转、双视角及沉浸截图。来源计划固定保留，当前标签页的工作不受影响。
- **复制并编辑**：新标签页获得独立副本，可以使用已有创作工具。设置中的「保存到本机」保存该副本的工作状态；刷新同一副本地址会恢复。
- **保存当前版本**：在「精选示例」面板填写名称，保存为独立版本，记录当前时刻。每次保存创建新条目，不覆盖旧版本。
- **导出／导入示例包**：备份完整计划及内嵌的组件、氛围库、编排、来源和引擎版本。导入创建新的本机版本。普通计划 JSON 仍使用旅程设置里的导入入口。

本机示例最多保存 20 个版本，每包不超过 2MB。浏览器清除站点数据会删除本机保存；请导出重要版本。配额不足或数据损坏会明确报错，不覆盖原数据。录音不包含在示例包中；编辑副本后可通过现有导入入口选择自己有权使用的音频。

## 保存边界

精选文件位于 `public/featured/`，来源记录见 `provenance.json`。原始方案数值保留在示例包内；运行时只验证和使用克隆，不把新库合并进原始计划。当前引擎回放并不保证跨引擎像素一致。原 V5 冻结运行版本仍保留在开发机，未将旧引擎或私有开发历史复制进公开仓库。

本次只提供人工选择的示例入口和独立版本保存，不增加模型调用、自动评优、在线账号或发布服务。
